## Зорилго

Charter-д тулгуурласан 60 минутын exploratory session хийж, бодит ажиглалт, нотолгоонд үндэслэн согогуудыг баримтжуулна.

## Баримтууд

- charter.md — session эхлэхээс өмнөх төлөвлөгөө.
- session-report.md — бодит цагтай түүхий тэмдэглэл, саад, цагийн задаргаа.
- bugs/ — дахин гаргах алхамтай согогийн тайлангууд.
- screenshots/ — UI согогийн зураг.
- evidence/ — API хүсэлтийн HTTP статус, толгой, биетэй бүтэн гаралт.

## Дүгнэлт

Supermodel аялал нь энэ session-д хамгийн олон зөрүү илрүүлсэн.
Энэ аяллын явцад тоолуурын BUG-01, оны дүрслэлийн BUG-02, товчны өнгөний BUG-03 согогуудыг ажигласан.
Мөн хоосон оролтын BUG-05, хайлтын BUG-06, давхардлын BUG-07, оны шалгалтын BUG-08 согогуудыг илрүүлсэн.
Холбоосын BUG-09, устгасны дараах мессежийн BUG-10, урт гарчгийн байрлалын BUG-11 нь хэрэглэгчийн үйлдэл болон дэлгэцийн үр дүнг харьцуулахад илэрсэн.
Saboteur аяллаар буруу JSON хүсэлтэд амжилттай хариу буцаадаг BUG-04-ийг илрүүлж, BUG-09-ийн HTTP 500 статусыг нэмэлтээр баталгаажуулсан.
Charter-ийн хамрах хүрээнээс гадуур илэрсэн гэж тусад нь бүртгэсэн согог байхгүй.
Зөвхөн зайтай оролт, өөр браузер, өөр дэлгэцийн хэмжээ болон API-ийн бусад хүчингүй өгөгдлийн хувилбарууд бүрэн шалгагдаагүй үлдсэн.
Дараагийн session-ийн charter-ийг эдгээр чиглэлд төвлөрүүлж, зөвшөөрөгдөх ба хүчингүй оролтын хамралтыг өргөжүүлнэ.
Лаб 1-ийн Playwright тестэд тохирох assertion нэмсэн тохиолдолд тоолуур, оролтын шалгалт, хайлт, давхардал, холбоос, мессежийн согогуудыг автоматжуулж барих боломжтой бөгөөд API-ийн статусыг мөн автоматаар шалгаж болно.
Товчны өнгө, оны формат, урт гарчгийн байрлалын зөрүүг хүний нүдээр анзаарахад хялбар байсан боловч эдгээрийг ч өнгө, текст, байрлалын тусгай автомат шалгалтаар барих боломжтой.
