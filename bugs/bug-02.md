# BUG-02: Номын оныг мянгатын таслалтай харуулдаг

## Орчин

- Апп: Уншлагын жагсаалт v2.0
- Сервер: Ubuntu / WSL, Node.js v22.22.1
- Браузер: Microsoft Edge 155.0.4283.45 (64-bit)
- Браузерын үйлдлийн систем: Windows 11 25H2
- Огноо: 2026-10-15

## Урьдчилсан нөхцөл

Серверийг Ctrl+C-ээр зогсоож, node app.js командаар шинээр асаасан, анхны 3 номтой байна.

## Дахин гаргах алхам

1. http://localhost:3000 хаягийг нээнэ.
2. Хуудсыг шинэчилнэ.
3. Анхны гурван номын «Он» баганыг ажиглана.

## Хүлээгдэж байсан

Спецификацийн дагуу он хүснэгтэд энгийн тоогоор харагдана.
Анхны номуудын он 1971, 2008, 1999 гэж харагдах ёстой.

## Бодит үр дүн

Анхны номуудын он 1,971, 2,008, 1,999 гэж мянгатын таслалтай харагдсан.

## Ноцтой байдал

Cosmetic — оны харагдах формат шаардлагатай зөрсөн боловч энэ ажиглалтаар хадгалсан утга өөрчлөгдсөн гэж дүгнээгүй.
