# BUG-03: Устгах товч улаан бус ногоон харагддаг

Орчин: Уншлагын жагсаалт v2.0; Edge 155.0.4283.45 (64-bit);
Windows 11 25H2; сервер Ubuntu/WSL, Node.js v22.22.1.
Огноо: 2026-10-15.

Урьдчилсан нөхцөл: Серверийг Ctrl+C-ээр зогсоож,
node app.js командаар шинээр асаасан, анхны 3 номтой байна.

## Дахин гаргах алхам
1. http://localhost:3000 хаягийг нээнэ.
2. Хуудсыг шинэчилнэ.
3. Номын мөрүүдийн Устгах товчнуудын өнгийг ажиглана.

Хүлээгдэж байсан: Спецификацийн дагуу аюултай үйлдлийн
Устгах товч улаан өнгөтэй байна.

Бодит үр дүн: Устгах товчнууд ногоон өнгөтэй харагдсан.

Ноцтой байдал: Minor — аюултай үйлдлийг шаардсан өнгөөр ялгаагүй.
