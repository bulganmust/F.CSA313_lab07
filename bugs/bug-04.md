# BUG-04: Буруу JSON хүсэлтэд HTTP 400 бус 200 OK буцаадаг

Орчин: Уншлагын жагсаалт v2.0; Ubuntu/WSL;
Node.js v22.22.1; curl 8.18.0.
Огноо: 2026-10-15.

Урьдчилсан нөхцөл: Серверийг Ctrl+C-ээр зогсоож,
node app.js командаар шинээр асаасан, анхны 3 номтой байна.

## Дахин гаргах алхам
1. Сервер ажиллаж байхад хоёр дахь Ubuntu терминал нээнэ.
2. Доорх командыг ажиллуулна.
3. HTTP статус болон хариуны body-г шалгана.

    curl -i --max-time 15 -X POST http://localhost:3000/api/books -H 'Content-Type: application/json' --data-binary 'буруу оролт'

Хүлээгдэж байсан: Спецификацийн дагуу буруу JSON биетэй
POST хүсэлтэд HTTP 400 буцаана.

Бодит үр дүн: HTTP/1.1 200 OK статус,
{"result":"OK"} body буцсан.
Шинээр асаасан апп дээр давтан шалгахад мөн давтагдсан.

Ноцтой байдал: Major — API хүчингүй JSON хүсэлтийг
амжилттай гэж мэдээлж байна.
